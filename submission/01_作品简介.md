## 二、用户与场景

- **目标用户**：应届生/实习生、工作 2–4 年想转行者、新晋管理者、关系困境者、长期投入决策者（考研/留学/创业）。
- **场景痛点**：人生重大决策时只有成功学与鸡汤，没有"真实走过的人"的经验教材；人类经验丰富，却无法被规模化"学习"。
- **机会窗口**：课程教知识，社区分享故事，AI 问答给建议——但没有一个系统负责把"别人经历过的人生"转成"我可以照着练的方法"。

## 三、解决方案：3-Agent 学习闭环

路书不是泛聊天机器人，不是单点问答工具，不是内容生成器，而是一个围绕真实处境跑通 **理解 → 检索 → 迁移 → 验证** 教育闭环的 AI Agent 应用：

1. **Context & Theme Agent（理解题）**：解析用户真实处境（阶段/行业/困惑），做 K/M/E/V/S 五类缺口诊断，生成个人画像。
2. **Experience Retrieval Agent（找前人）**：在路书库检索相似经历（**14 位跨时代名人/历史人物** + 真实内测样本），对常见坑做提醒，并用"来源可核查"的对话陪用户聊（不虚构）。
3. **Learning Journey Agent（变能力）**：从前人经历提炼方法卡，生成工作选择尺、未来分岔推演、7 天行动与打卡复盘。

**闭环证据**：3-Agent Trace 记录每一次决策的数据流；用户侧"写一页给后来的人 → 脱敏入库 → 被后来人检索"形成数据飞轮，越用越厚。

## 四、核心创新

1. **把"经验讲述"升级为"经验学习"**：不做语录、不做传记搬运，名人一生被结构化为一本可学习、可练习、可验证的"路书"（有选择、有代价、有后悔、有可拆解技能卡、有 1/3/5/7 年时间轴）。
2. **名人路书图书馆战略（冷启动解法）**：名人/历史人物人生是公开史料，天然可结构化、可追溯、可规模化制作；普通人 UGC 路书库随后开启，形成"名人引路 + 众人添砖"双层内容飞轮。
3. **可复用的 Open Roadbook Protocol**：Roadbook Case / Formula Card / Learning Skill 三类 Schema + 3-Agent Trace，可作为经验学习模板供社区共建复用。
4. **「学习模式」路径生成（V0.9.9）**：用户没写困惑也能自动从读过的书里提炼学习路径；写困惑则输出更贴合境况的定制路径。
5. **演示绝对可靠**：LLM 输出强类型归一化 + 全局错误边界（白屏零容忍）；内置 Fixture-first 规则引擎，无 API Key 也能完整体验，配置真实 LLM（DeepSeek）失败自动回退，演示永不崩。

## 六、合规与安全边界

- **来源清晰**：名人/历史人物案例均标注公开来源（一手文献 + 公开传记/史料双来源），绝不虚构；学术界有争议处如实标注。
- **隐私保护**：用户贡献自动脱敏（手机号/邮箱/薪资），可自主选择公开粒度；贡献即授权匿名化入库，可随时撤回。
- **风险提示**：不替用户做决定、不预测命运，只做情景推演；重大决策须结合现实与专业意见。
- **行业边界**：聚焦个人成长与职业决策，不进入医疗/法律/金融投顾等需资质领域。
